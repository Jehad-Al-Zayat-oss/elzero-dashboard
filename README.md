# Elzero Dashboard

A responsive multi-page dashboard built using HTML5 and CSS3, based on Elzero Web School's course.

## Live Demo

**[View Live Demo]()**

## About The Project

This project is a multi-page dashboard consisting of 8 different HTML pages, created as part of my frontend development learning journey.

The main goal of this project was to practice building responsive layouts and improve my understanding of modern CSS layout techniques.

## Features

- 8 different HTML pages.
- Fully responsive design.
- Modern and organized dashboard layout.
- CSS Grid for complex layouts.
- Flexbox for flexible element alignment.
- Consistent navigation and UI components.
- Clean and structured code.

## Technologies Used

- HTML5
- CSS3
- CSS Grid
- Flexbox
